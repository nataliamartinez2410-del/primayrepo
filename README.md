# Mis Tareas

App web sencilla para organizar tareas diarias.

## Funciones

- Crear tareas con prioridad, categoría y fecha.
- Marcar tareas como completadas.
- Filtrar todas, pendientes o completadas.
- Buscar tareas.
- Eliminar tareas o limpiar las completadas.
- Guardado automático en `localStorage` del navegador.
- Diseño adaptable a computador y celular.

## Uso

Abre `index.html` en un navegador. No necesita servidor ni base de datos: las tareas se almacenan localmente en el dispositivo.
